# Roulette

<img width="360" height="512" alt="image" src="https://github.com/user-attachments/assets/e252de7d-6141-4fcf-9eec-41edddad33a5" />


The circuit simulates a roulette wheel using **LEDs** (red, yellow, green).  
While the button is held, the "roulette ball" spins around the wheel.  
When the button is released, it stops at a **random position**.
